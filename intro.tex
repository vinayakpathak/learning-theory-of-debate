As AI models grow in capabilities, how do we ensure that they continue to act in the interest of humans? A long line of work~\citep{yudkowsky2008artificial,soares2015corrigibility,russell2015research,amodei2016concrete,everitt2017corrupted,soares2017agent,armstrong2018occam,soares2018value,hubinger2019risks,taylor2020alignment,skalse2022reward} has argued that this is a hard problem, and recent events such as the infamous HuggingFace incident~\citep{openai2026huggingface} have demonstrated the difficulties in practice. 

One way to study this problem more formally has been termed \emph{scalable oversight}. Here, it is assumed that our true preferences are encoded by a function $f: X \rightarrow Y$ that is hard for us to compute, but easy for an AI. For example, suppose $x \in X$ encodes the current state of the world and $y \in Y$ is the desired action. If this involves long-term planning then $f$ can be hard to compute for us. There are many reasons for why an AI can be more powerful than us and the scalable oversight literature assumes that the reason is largely computational. For example, the early works assumed that $f$ was a PSPACE-complete problem and that an AI was able to solve it~\citep{irving2018debate}, while a human was only able to solve problems in P. Some more recent works assume other kinds of computational superiority~\citep{browncohen2024debate,browncohen2025prover}. Since we are not able to compute $f$ ourselves, it is unclear how: a) we can provide the correct supervision during training so that the AI learns to compute $f$, and b) check that a trained AI is indeed computing $f$. Scalable oversight aims to provide an answer. However, the currently existing literature has mostly focused on (b) while largely ignoring (a). 

That (b) might be achievable can be seen using the following analogy that appeared in~\cite{irving2018debate}. Suppose $x$ represents a SAT instance and $y$ denotes whether it is satisfiable. To prove to the human that $y=\mathrm{true}$, the AI just needs to provide the satisfying assignment along with $y$. In general, the scalable oversight literature assumes that $f$ sits within some level of the polynomial hierarchy, thus providing a means to certify whether AI's solution is correct. For example, if we assume $f$ to be in $\Sigma_{2k}^{\mathrm{P}} \cap \Pi_{2k}^{\mathrm{P}}$, then this means there exists a polynomial time verifier $v$ such that for all $x$, the correct answer is $y$ iff $\exists c_1 \forall c_2 \ldots \exists c_{2k-1} \forall c_{2k} v(x,y,c_1,\ldots ,c_{2k}) = \mathrm{true}$. This motivates the \emph{debate} protocol~\citep{irving2018debate,browncohen2024debate}, where the AI is thought of as a collection of two \emph{debaters} (also implemented as AI models). Given $x$, the \dt proposes a $y$ and tries to defend it. The \df argues for the opposite label. The two debaters generate arguments $c_1,c_2,\ldots , c_{2k-1},c_{2k}$, and the human judge $v$ judges whether the debate transcript proves that the answer to $x$ is $y$. The \dt's goal is to make the verdict `yes' and the \df's goal is the opposite. Due to the definition of this complexity class, one has the guarantee that the \dt has a winning strategy for a given $x$ if and only if its proposed label is equal to $f(x)$. The union $\bigcup_k (\Sigma_{2k(|x|)}^{\mathrm{P}} \cap \Pi_{2k(|x|)}^{\mathrm{P}})$ over all polynomially bounded functions $k$ is PSPACE, and thus it's tempting to say that a human judge could potentially supervise models that solve problems in PSPACE (which was indeed the motivation presented in the first paper on debate~\citep{irving2018debate}).

As mentioned above, this analysis misses the important aspect of \emph{learning}. Just because the existence of \dt's winning strategy is equivalent to the \dt returning the correct label, it does not imply that the it can actually \emph{find} that winning strategy. Moreover, it is likely that the advantage that a superhuman AI might have over humans is not as much about computation as about the ability to learn facts about the universe that humans haven't learned. Indeed, due to the extended Church-Turing thesis~\citep{vergis1986complexity, aaronson2005physical}, a superhuman intelligence, no matter how intelligent it gets, is unlikely to be solving worst case instances of NP-hard problems, let alone PSPACE-hard problems. If an AI is seemingly able to solve NP-hard problems (such as AlphaFold~\citep{jumper2021alphafold}), it is likely because it has \emph{learned} something about the distribution from which the universe is creating the input instances. Thus learning should be at the centre of any investigation into scalable oversight.

\subsection{Our results}
We model debate as an online learning problem. Nature produces a sequence of $x_t$'s, and at each $t$, two debaters produce a sequence of certificates. The human is modeled by a verifier $v$ as above. Thus given $x_t$, a proposed $y_t$, and a debate transcript, $v$ can decide whether the transcript proves that $y_t$ is the correct label for $x_t$. Each $v$ induces a ground truth hypothesis $h$. The debaters need to learn $h$. They don't know $v$ (because otherwise they would also know $h$) but know a class $\V$ that $v$ lies in. A \emph{mistake} is when the $y$ proposed by the \dt is different from the true label. In the \emph{realizable} case, we assume that $v$ is consistent with the ground truth at each round.

Modeled this way, the learning problem becomes explicit and already opens up an intriguing possibility: is it always better for the debaters to play adversarially? For example, can there be a case where the learning problem is solved more quickly if the two debaters cooperate? We answer this in the affirmative in Section~\ref{sec:cooperative-example}, where we show that there exist instances of the debate problem where learning is impossible when the debaters are adversarial, but can be done with a constant number of mistakes if they cooperate.

Motivated by this example, we define the \emph{cooperative} version of the problem where the debaters work towards the joint goal of using access to $v$ in the most efficient way in order to learn the ground truth. We present a characterization for when a finite number of mistakes can be achieved in the realizable setting (Section~\ref{sec:cooperative-case}). 

One common criticism of the debate protocol is that it assumes the infallibility of humans~\citep{irving2019social,browncohen2024debate,parrish2022single,parrish2022two}. It is unclear that a human can implement such a robust $v$ that aligns with the ground truth on all $x$. Thus we consider an unrealizable version of the problem where we assume that $v$'s output can be arbitrarily corrupted during some of the rounds. We call these rounds \emph{misspecified}, and show that for every constant $d > 1$, there are instances of the problem where if there are $k$ misspecified rounds, then every deterministic learner makes at least $\Omega(dk)$ mistakes.
