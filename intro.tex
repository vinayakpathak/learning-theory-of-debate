As AI models grow in capabilities, how do we ensure that they continue to act in the interest of humans? A long line of work~\citep{yudkowsky2008artificial,soares2015corrigibility,russell2015research,amodei2016concrete,everitt2017corrupted,soares2017agent,armstrong2018occam,soares2018value,hubinger2019risks,taylor2020alignment,skalse2022reward} has argued that this is a hard problem, and recent events such as the infamous HuggingFace incident~\citep{openai2026huggingface} have demonstrated the difficulties in practice. 

One way to study this problem more formally has been termed \emph{scalable oversight}. Here, it is assumed that our true preferences are encoded by a function $f: \X \rightarrow \Y$ that is hard for us to compute, but easy for an AI. For example, suppose $x \in \X$ encodes the current state of the world and $y \in \Y$ is the desired action. If this involves long-term planning then $f$ can be hard to compute for us. There are many reasons for why an AI can be more powerful than us. The scalable oversight literature assumes that the reason is largely computational. For example, early works assumed that $f$ was a PSPACE-complete problem and that an AI was able to solve it~\citep{irving2018debate}, while a human was only able to solve problems in P. Some more recent works assume other kinds of computational superiority~\citep{browncohen2024debate,browncohen2025prover}. Since we are not able to compute $f$ ourselves, it is unclear how we can: a) design a training process that teaches a model to compute $f$, and b) check that a trained AI is indeed computing $f$. Scalable oversight aims to provide an answer. However, the currently existing literature has mostly focused on (b) while largely ignoring (a). 

That (b) might be achievable can be seen using the following analogy that appeared in~\cite{irving2018debate}. Suppose $x$ represents a SAT instance and $y$ denotes whether it is satisfiable. To prove to the human that $y=\mathrm{true}$, the AI just needs to provide the satisfying assignment along with $y$. In general, the scalable oversight literature assumes that $f$ sits within some level of the polynomial hierarchy, thus providing a means to certify whether AI's solution is correct. For example, suppose $f$ lies in the intersection of the two classes at level $2n$ of the polynomial hierarchy (at level 1, these are NP and co-NP).\footnote{Formally, this is the class $\Sigma_{2n}^{\mathrm{P}} \cap \Pi_{2n}^{\mathrm{P}}$.} Then there exists a polynomial time verifier $v$ such that for all $x$, the correct answer is $y$ iff $\exists c_1 \forall c_2 \ldots \exists c_{2n-1} \forall c_{2n}\, v(x,y,c_1,\ldots ,c_{2n}) = \mathrm{true}$. This motivates the \emph{debate} protocol~\citep{irving2018debate,browncohen2024debate}, where the AI is thought of as a \sout{collection of two}\sivan{pair of} \emph{debaters} (also implemented as AI models). Given $x$, the \dt proposes a $y$ and tries to defend it. The \df argues for the opposite label. The two debaters  generate alternating arguments $c_1,c_2,\ldots , c_{2n-1},c_{2n}$, and the human judge $v$ judges whether the debate transcript proves that the answer to $x$ is $y$. The \dt's goal is to make the verdict `yes' and the \df's goal is the opposite. Due to the definition of this complexity class, one has the guarantee that the \dt has a winning strategy for a given $x$ if and only if its proposed label is equal to $f(x)$. If we allow the number of rounds of the debate to grow polynomially with the size of $x$, the problems whose answers can be certified this way are exactly those in PSPACE, and thus it is tempting to say that a human judge could potentially supervise models that solve problems in PSPACE (which was indeed the motivation presented in the first paper on debate in \citealp{irving2018debate}).


However, as mentioned above, the current literature ignores the important part (a), namely, how do we ensure that a model \emph{learns} the correct function $f$. Just because the existence of \dt's winning strategy is equivalent to the \dt returning the correct label, it does not imply that the winning strategy can be found. Moreover, it is likely that the advantage that an AI might have over humans is not as much about computation as about the ability to learn facts about the universe that humans haven't learned. Indeed, according to the extended Church-Turing thesis~\citep{vergis1986complexity, aaronson2005physical}, every phyically realizable computer can be \emph{efficiently} simulated by a (quantum) Turing machine. Thus, a computational intelligence, no matter how ``superhuman'' it gets, is unlikely to be solving worst case instances of NP-hard problems, let alone PSPACE-hard problems. If an AI is seemingly able to solve NP-hard problems (such as AlphaFold~\citep{jumper2021alphafold}), it is likely because it has \emph{learned} something about the distribution from which the universe is creating the input instances. Thus, we claim that learning should be at the centre of any investigation into scalable oversight.

\subsection{Our results}
We model debate as an online learning problem. Nature produces a sequence of $x_t$'s, and at each round $t$, two debaters produce a sequence $\sc_t$ of certificates. The human is modeled by a verifier $v^*$ as above. Thus, given $x_t$, a proposed $\hy_t$, and a debate transcript $\sc_t$, $v^*$ can decide whether the transcript proves that $\hy_t$ is the correct label for $x_t$ and provides this feedback to the learner. Each verifier $v$ induces a ground truth hypothesis $h$. The debaters need to learn the true $h^*$. They don't know the true $v^*$ (because otherwise they would also know $h^*$) but know a class $\V$ that $v^*$ lies in. A \emph{mistake} is when the label $\hy_t$ proposed by the \dt is different from the true label $h^*(x_t)$. In the \emph{realizable} case, we assume that  the feedback is consistent with the true $v^*$ at each round.

Modeled this way, the learning problem becomes explicit and already opens up an intriguing possibility: is it always better for the debaters to play adversarially? For example, can there be a case where the learning problem is solved more quickly if the two debaters cooperate? We answer this in the affirmative in Section~\ref{sec:oppositional}, where we show that there exist instances of the debate problem where learning is impossible when the debaters act adversarially to each other, but can be done with a constant number of mistakes if they cooperate.

One common criticism of the debate protocol is that it assumes the infallibility of humans~\citep{irving2019social,browncohen2024debate,parrish2022single,parrish2022two}. It is unclear that a human can implement such a $v$ that aligns with the ground truth on all $x$. Thus, we also consider an unrealizable version of the problem, in which we assume that $v$'s output can be arbitrarily corrupted during some of the rounds. We call these rounds \emph{misspecified}, and show that for every constant $d > 1$, there are instances of the problem such that in the realizable setting, the optimal deterministic mistake bound is $d$, while if there are $k$ misspecified rounds, then every deterministic learner makes at least $\Omega(dk)$ mistakes\sivan{add section reference when we have it}. This contrasts with Online Learning, in which any hypothesis class with a finite Littlestone dimension $L$ admits a ``no-regret'' algorithm for the $k$-non-realizable setting with a mistake upper bound of $k +O(\sqrt{k\cdot L} + L)$, implying that the prediction error rate converges to the misspecification rate \citep{FilmusHaMeMo23,BenDavidPaSh09,AlonBeDaMoNaYo21}. The lower bound for debate learning shows that debate learning is significantly more  sensitive to misspecification errors: even a small rate of misspecification errors can induce an unreasonably large prediction error, and the error rate may never approach the misspecification rate.
