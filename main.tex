We let $\X$ denote a \emph{domain}, $\Y = \{0,1\}$ a binary \emph{label space}, and $\C$ a \emph{certificate space}.  
A \emph{hypothesis} is a function $h:\X\to\Y$, and we use $\H$ to denote a \emph{hypothesis class}.
A \emph{debate of length} $n$ is a sequence $(\c_1, \c_2, \ldots, \c_{2n})$ of $2n$ certificates $c_i\in\C$. We think of these certificates as being produced alternately by two debaters. That is, we think of the certificates $c_i$ of odd index as being produced by the first debater, which we will call the \dt, and the certificates $c_i$ of even index by the second debater, which we will refer to as the \df. To clarify the role of the arguments in the debate, we usually will use the notation $(\ct^1, \cf^1, \ct^2, \cf^2, \ldots,  \ct^n, \cf^n)$ for a debate of length $n$

The debate is moderated through a \emph{verifier} $v: \X\times \C^{2n} \to \Y$ which takes in a domain point and a debate of length $n$ and produces a label for $x$ given the arguments in the debate. The following definition specifies the relationship between hypotheses and verifiers in our framework.

\begin{definition}
Let $h:\X\to\Y$ be a hypothesis. We say that verifier $v: \X\times \C^{2n} \to \Y$ \emph{validates} hypothesis $h$ through debate of length $n$ if

We will study for which verifier classes $\V$ the above protocol leads to a finite mistake bound (or sublinear regret) for the debate evaluation. We will distinguish between the \emph{cooperative case} and the \emph{combative case}. In the cooperative case both debaters are acting cooperatively so as to minimize the debate evaluation measures. We can think of this as a scenario where debater \df provides its certificates in good faith ``for the sake of the argument'' so as to lead the verifier to the correct conclusions having taking into account relevant potential counter-arguments. In contrast, in the combative case, both debaters are acting in a way to minimize their own evaluation measures respectively. Thus in this case, even debater true may put up hypothesized labels $\hy_t$ that it knows it can argue for even through it is already aware the this does not correspond to the underlying truth $y^*_t$. We study whether the true underlying hypotheses can be recovered in both scenarios.

\section{The Cooperative Case}
\label{sec:cooperative-case}
In this section, we start by exploring the cooperative case of learning via debate. To analyze which classes $\V$ of verifiers allow for learning with finite mistake bound, we will define a tree structure that represents potential runs of the debate protocol for debate length $n$.

As usual in these types of trees, the nodes correspond to actions of the (potentially adversarial) environment. In our case, this includes the verifier's evaluations $\vy$. The edges in the tree record the debaters' actions. That is, an edge records the label $\hy$ that the \dt poses, as well as the debate $\sc$ of length $n$ that then ensues between the two debaters. A non-root node records the verifier's evaluation of the debate on the incoming edge for the domain point from the previous round, recorded in the node's parent, as well as the new domain instance that the environment poses for the next round.
The root node only records the instance that the protocol is initiated with.


\begin{definition}[Debate Tree]
Given a debate length $n$ and a verifier class $\V$, we define a \emph{length-$n$-debate tree for class $\V$} to be a directed tree $\T$ with the following properties:
\begin{enumerate}
    \item Every node $\alpha$ in $\T$ is a pair of a domain point and a label $\alpha=(x_\alpha, \vy_\alpha)$.
    \item The root node is denoted by $\rho$. Its domain point is denoted by $x_\rho$, and its label is $\vy_\rho = \sqcup$, where $\sqcup\notin\Y$. \item The root node $\rho$ is the only node in $\T$ with associated label $\vy_\rho \notin\Y$: for all nodes $\alpha\neq \rho$, we have $\vy_\alpha\in \Y$.
    \item Edges $(\alpha, \beta)$ in $\T$ are directed away from the root node, and annotated with a label $\ell^\alpha_\beta = (\hy^\alpha_\beta, \sc^\alpha_\beta)$, where $\sc^\alpha_\beta = (\ct^1_{\alpha\beta}, \cf^1_{\alpha\beta}, \ct^2_{\alpha\beta}, \cf^2_{\alpha\beta}, \ldots,  \ct^n_{\alpha\beta}, \cf^n_{\alpha\beta})$ is a debate of length $n$.
    % We will denote edges by triples
    % \[
    % (\alpha, \ell, \beta) = ((x_\alpha, y_\alpha), (\hy^\alpha_\beta, \sc^\alpha_\beta),  (x_\beta, y_\beta)).
    % \]
    \item For each non-leaf node $\alpha$ and each possible edge annotation $(\hy, \sc)$, there is exactly one child node $\beta$ to $\alpha$ with $\ell^\alpha_\beta = (\hy, \sc)$
    \item All directed paths in $\T$ are finite, and consistent with a verifier $v\in\V$ (in the sense defined below).
\end{enumerate}
We let $\Delta_n(\V)$ denote the set of all length-$n$-debate trees $\T$ for verifier class $\V$.
\end{definition}

\subsection{Non-realizable case}
We will now consider the case in which instead of knowing a class perfectly, there exists some noise feedback, or misspecification.
Formally, we will consider the $k$-nonrealizable case, i.e., situations in which all but $k$ rounds are consistent with the behaviour of a verifier $v\in \V$.

\begin{theorem}
    For every $d$ and every $n$, there exists a class $\V_{d,n}$ with $\dldim(\V_d)=d$ and such that every deterministic learner makes $\Omega(kd)$ mistakes in the $k$-non-realizable case.
\end{theorem}
\begin{proof}
    Consider $\X= \C = \naturals$.  Consider $\mathcal{H} = \{h_a: \X \to \Y: a\in \{0,1\}\}$, where $h_a(x) = a$ for all $x\in \mathcal{X}$. We now will construct a verifier class, that is easy to learn in the realizable setting but hard to learn in the $k$-non-realizable setting.
  To ensure that the class we construct is indeed a verifier class for $\mathcal{H}$ we will consider verifiers $v$, such that there exists $h\in \mathcal{H}$ and $b\in \{0,1\}$ with:
  \begin{itemize}
      \item For all $x \in \mathcal{X}$, for $c_1 =1$, $\forall c_2, c_3 = 1, \forall c_4, \dots, c_{2n-1}= b, \forall c_{2n}  $: $v(x, c_1. c_2, c_3,c_4, \dots, c_{2n-1}, c_{2n}) = h(x) $.
