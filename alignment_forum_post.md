Debate is a popular training protocol that is believed to be a promising approach to the problem of scalable oversight. Even though it is a training protocol, not a lot is known about its learning behaviour. A new [paper](https://arxiv.org/abs/2611.17303) that I coauthored with [Tosca Lechner](https://toscalechner.github.io/), [Sivan Sabato](https://www.cas.mcmaster.ca/sivansabato/), and [Ruth Urner](https://www.eecs.yorku.ca/~uruth/) takes the first steps towards analyzing the learning theoretic aspects of debate. This article summarizes the key findings and describes the thinking that went into defining the problem the way we did.

## Summary and key findings

- Most present work on debate studies its computational aspects. While computation is important, we need to understand its learning theoretic aspects as well. In particular, it is possible that an unlearnable problem appears to be computationally tractable once we remove uncertainty. This should not give us the false hope that the problem is tractable.
- Once we precisely define the learning problem underlying scalable oversight, we show that debate is not always the best way to solve it.
- The learning problem underlying scalable oversight also does not appear to be robust against human errors. Assuming a perfectly accurate human is unrealistic. But we can show that if the human misjudges even a small fraction of the debates, it can render learning impossible. Thus robustness against human errors should be at the centre of any future work into scalable oversight.
- All the obstacles above are _information theoretic_, i.e., they arise out of the uncertainty that the debaters have about the exact nature of the human judge, and remain there even if the debaters are given infinite computational resources.

## The problem of scalable oversight

In the early days of AI, it was hoped that one could create a superintelligence simply by writing its code directly. But it turned out that even mild intelligences, that can recognize whether a picture is of a cat or not, are hard to create in this way and thus we have to resort to supervised learning. The idea behind supervised learning is that even though we cannot write down the precise definition of a cat in the form of an algorithm, we can tell if a given picture is of a cat or not. Thus all we need to do is write the code for a _learner_ that looks at many examples of pictures of "cat" vs "not a cat" and writes down its own code for identifying cats. Such learners have now been built, and understanding when such a learner is possible to be built gave rise to the rich field of learning theory.

But what about more general problems than simply identifying cats? Ideally we would like to automate a lot more things that we are not able to write the code for. We would like AI to cure diseases, build useful things for humans, and accelerate scientific progress. If we can't directly write code for doing this, can we build a learner that learns how to do it? In a very general sense, we want an algorithm that takes in the state of the world as its input, and outputs the best possible next action. If we could provide lots of examples of (state of the world, best next action) pairs, then we could hope that a general purpose supervised learner would already work. However, computing the best possible next action is very challenging for a human being. Thus we need to study a different kind of learning problem.

Even though we can't compute the next best action, it is feasible that we can provide some other kind of feedback that is useful for the learner. For example, the learner can show us the entire trajectory that the world would take starting from its proposed next action. Presumably, we can then judge whether we like the trajectory or not and give our judgement back to the learner as feedback. The problem of scalable oversight asks, what is the feedback we can continue to provide to a learner as it tries to learn to accomplish more and more complex tasks? Ideally we would like to show that there exists a certain kind of feedback that we can actually compute that ensures that the learner learns the correct thing even as it grows more and more powerful.

## A complexity theoretic analogy

Following the "AI safety via debate" [paper](https://arxiv.org/abs/1805.00899) by Irving et al, we can consider the simpler question where the learner has finished learning and just needs to convince us that it has learned the right thing. Presumably, we need to be able to understand this certification problem before we can solve the learning problem. If we can't even tell if the learner has learned the right thing, then we can't really hope to direct it towards learning the right thing.

Then, for the problem of certification, we can attempt to understand the largest class of problems that can be certified by a human. Assume that a human is someone who can solve problems in P. The learner is something that can solve problems in a higher complexity class. For what classes does the learner have a way of proving to the human that it has found the correct solution? For example, suppose the learner can solve problems in the class $\mathrm{NP} \cap \text{co-NP}$. This means, there exists a polynomial time algorithm $v$ such that for every $x$ and $y$, there exists some certificate $c$ such that $v(x,y,c)$ returns true if $y$ is the correct label for $x$ and if $y$ isn't the correct label for $x$ then no certificate $c$ exists that can make $v(x,y,c)$ return true. Since $v$ is a polynomial time algorithm, a human can implement it. Thus we can ask the learner to produce both $y$ and $c$ for any given $x$ and we can ask the human to evaluate $v(x,y,c)$.

More generally, we can consider the entire polynomial hierarchy. Here, we have a constant number $k$ of certificates $c_1, c_2, \ldots, c_k$, each of length polynomial in the length of $x$. There exists a polynomial time algorithm $v$ such that if $y$ is the correct label, there exists a $c_1$ such that for every $c_2$, there exists a $c_3$, and so on, such that $v(x,y,c_1,c_2,\ldots,c_k)$ returns true. If $y$ is incorrect, then for every $c_1$ there exists a $c_2$ such that for every $c_3$, and so on, $v$ returns false. Since $v$ is polynomial time, we assume that a human can implement it. If we allow the number $k$ of rounds to grow polynomially with the input size then the resulting class is $\mathrm{PSPACE}$.

The process of generating the sequence of $c_i$'s looks like a _debate_ between two debaters. The argument above shows that a polynomial time human can judge whether the answer to a problem in PSPACE is correct or not given the debate transcript consisting of the sequence of $c_i$'s. In particular, given any input $x$ and a candidate answer $y$, consider the game played between two debaters where each debater takes turns to compute certificates $c_i$'s. Once the entire transcript is generated, it is given along with $x$ and $y$ to the human and the payoff of the first debater is 1 if the human judges the transcript to be a valid argument for certifying that $y$ is the answer to $x$ and 0 otherwise. The payoff of the second debater is the opposite of the payoff of the first, thus making it a zero sum game. The argument above shows that assuming the original problem is in PSPACE and that the human judge can implement $v$, the first debater has a winning strategy for a pair $x, y$ if and only if $y$ is the correct answer to $x$.

So going back to the original question, how can a learner convince the human that it has learned the right thing, assuming that the "right thing" is a PSPACE-complete problem whereas a human is only able to compute things in P? This can work if we have two debaters as described above that we are convinced are playing their optimum strategies. Then, given a transcript, if the human is convinced of its correctness, then that guarantees that the answer to $x$ is $y$.

But of course, the existence of efficient debaters is questionable. Indeed, if there was an efficient way of finding debate transcripts for all $x$, then PSPACE would be equal to P. Moreover, there is a more fundamental issue here. Thinking about the problem in purely computational terms misses the fact that it is, in the end, a learning problem. We are thinking of the procedure $v$ that judges a debate as something implemented by a human. Thus the debaters should only have limited and expensive access to it. They can potentially evaluate it on a limited number of debates and they should not rely on access to it to calculate the label for every single $x$. We can assume additional known information about $v$ by defining some class $V$ that we think $v$ lies in, but we should not assume that $v$ is known exactly. These questions need to be considered carefully and appropriate choices should be made in order to define a meaningful and realistic set up. We consider these issues in the next section.

## Scalable oversight as a learning problem

We follow Leslie Lamport's famous [advice](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/12/State-the-Problem-Before-Describing-the-Solution.pdf) and first precisely define the learning problem before attempting to solve it.

We can first review the standard learning theoretic setting to understand what goes into defining a learning problem. In the standard setting we want the learner to learn a function $h$ from a domain $X$ to a label set $Y$. For simplicity assume $Y = \{0,1\}$. One assumes that as humans we are able to evaluate $h$ on any given $x \in X$ but we cannot write down the code for $h$. If we know anything at all about $h$, we usually encode that in the form of a hypothesis class $H$ such that we think $h$ lies in $H$. For example, we might know that there exists a hyperplane that separates $x$'s with label 0 from $x$'s with label 1. In this case, $H$ can be the set of all separating hyperplanes. A learner is given the task to learn enough about $h$ so that it is able to achieve a good prediction performance.

To define a learning problem, we then need to make the following decisions.

1. **What kind of access does the learner get to $h$**? In the supervised learning set up, iid samples $x_1, \ldots, x_m$ are generated from some unknown distribution $P$ and the learner is allowed to obtain the label $h(x_i)$ for each $x_i$. For online learning, a framework that's robust against distribution shifts, the samples are generated by an adversary (instead of iid) and once again the learner is allowed to obtain the label of the samples generated. One can also study _query learning_ where the learner can query $h$ on any point $x$ that it desired.
2. **What counts as success?** In supervised learning, the learner is judged on the same distribution $P$ that the samples were generated from. In particular, we want the learner to achieve a low expected number of mistakes. In online learning, we count the number of mistakes as a function of the number of samples produced and we want this function to be sublinear. In query learning one usually wants the learner to identify $h$ exactly, i.e., success is if the learner can start to correctly label every single $x$.

For scalable oversight, humans aren't able to evaluate $h$, but can instead evaluate a verfier $v$ that can judge debates. Thus to define a learning problem, we need to decide the kind of access we want the learner to have to $v$. What one does with that access is part of the solution, not of the problem definition, and thus we will come to that later. In this paper we consider an online version of the scalable oversight problem, i.e., we assume that an adversary produces samples $x_i$'s and the learner is able to query $v$ using one chosen debate transcript per $x_i$. As the success criterion, we want the learner to make a sublinear number of mistakes. We think other variations are also worth investigating and we have left that for future work.

More precisely, The learning protocol proceeds in time steps, with the same unknown $h$ and $v$ throughout. At each time step $i$:

- The adversary gives the learner an input $x_i$.
- The learner predicts a label $\hat{y}_i$ for $x_i$.
- The learner generates both sides of a debate of fixed length $n$. In each of the $n$ exchanges, it chooses an argument for the first debater (called _proposer_) to make in support of $\hat{y}_i$ and then a reply for the second debater (called the _responder_). Call the resulting transcript $\tau_i$.
- The verifier returns the judgement $v(x_i, \hat{y}_i, \tau_i)$. This is the only feedback the learner receives.

We count a mistake whenever $\hat{y}_i \ne h(x_i)$. So even if the verifier agrees with the learner, the learner can still have made a mistake. Let $M(T)$ be the number of mistakes in the first $T$ time steps. We want the fraction $\frac{M(T)}{T}$ to go to zero as $T$ grows. In the paper we ask when the learner can guarantee a fixed bound on the total number of mistakes, independent of $T$.

For completeness, we also state two other decisions that we need to make to define the precise learning problem for the scalable oversight setting.

3. **What does the learner know in advance?** In the standard learning set up, any domain knowledge was encoded in the form of a hypothesis class $H$. We go with the same idea and assume there is a class $V$ of verifiers that $v$ lies in. However, this isn't the only way to encode domain knowledge, and in the future it will be worth studying other ways.
4. **How does $v$ relate to the true hypothesis $h$?** The promise of scalable oversight is that if we make $v$ to be the verifier for $h$ as is done in the polynomial hierarchy, then we should be able to supervise our learner to learn very complex functions. Thus for the present work, we stick with that correspondence. In the future, it will be useful to relax this and investigate what kinds of correspondences truly help us supervise advanced learners.

## Is debate the best solution?

Note that so far in the definition of the learning problem we have talked about a central learner that generates a debate transcript. We did not talk about debaters competing against each other to win the debate. This is because _how_ one learns in this setting is part of the solution, not of the problem definition. Once we have defined the problem precisely, we can _then_ ask whether instantiating competing debaters is indeed the optimal strategy for solving it.

Competing debaters is one specific learning strategy among the universe of all strategies. Thus it isn't clear apriori whether it is optimal. Of course, if the two debaters are allowed to cooperate and do whatever is required to get a small number of mistakes, then this cannot be worse than competing debaters. In the paper we provide examples where opposing debaters can be strictly worse than coopeartive ones.

If debate isn't the best solution then what is? In the paper we provide a learning algorithm along the lines of the [Standard Optimal Algorithm](https://ai.stanford.edu/~pabbeel/depth_qual/littlestone1988.pdf#page=7) for online learning that makes the optimum number of mistakes. We characterize the verifier classes $V$ for which this algorithm makes a finite number of mistakes.

## What about fallible humans?

In the scalable oversight literature it is generally assumed that a human is able to implement a debate judge $v$ for the learning problem at hand. But this may be an unrealistic assumption. In particular, the correspondence between $v$ and $h$ may break occasionally because humans are fallible. If that does happen, is the learning algorithm robust enough that it still learns the true $h$? If not, then that would be a serious limitation to debate as a solution to scalable oversight.

We model the fallibility of humans by saying that there are a few "misspecified" rounds in the learning protocol, i.e., rounds where the verifier $v$ outputs the wrong thing. We show examples of verifier classes $V$ where $k$ misspecified rounds can force the learner to make at least $\Omega(d k)$ mistakes for a constant $d$ of our choosing. Thus, for example, it's possible to construct cases where if the human judge misspecifies on say 1% of the rounds, the learner is forced to be no better than random guessing. This is in stark contrast with standard online learning, where if some hypothesis in the class is wrong on at most 1% of rounds and the class has finite Littlestone dimension, the learner can keep its expected mistake rate below 1% plus a term that goes to zero as $T$ grows.

## Next steps

In general, it is interesting to understand the possibility of learning a function $h$ when the available feedback is something other than evaluations of $h$. This is specially important as we try to train AI's to compute functions that we oursleves aren't able to compute. The proposal of the debate literature is to provide as feedback a judgement of a debate. While this sort of feedback is supported by potentially interesting complexity theoretic analogies, it is unclear whether it truly leads to algorithms that can learn complicated function classes. Moreover, not being robust to misspecifications is a serious flaw with this set up. In future work it will be good to understand if there is a kind of feedback that can actually meet the promises and hopes of scalable oversight.
